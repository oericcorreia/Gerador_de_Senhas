
# 🔐 Gerador de Senhas em Python

Este é um pequeno projeto de **gerador de senhas** feito com Python e interface gráfica em `tkinter`.

O objetivo é criar senhas seguras e aleatórias com apenas um clique. O projeto é aberto e está em constante evolução — sinta-se livre para estudar, usar ou modificar como quiser.

## 🧰 Tecnologias e Bibliotecas

- Python `3.x`
- `tkinter` – Interface gráfica
- `random` – Geração de dados aleatórios
- `string` – Manipulação de caracteres
- `os` – Manipulação de arquivos
- `datetime` – auxilia na manipulação de arquivos

## ⚙️ Como Executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/seu-usuario/gerador-senhas-python.git
   ```

2. Acesse o diretório:

   ```bash
   cd gerador-senhas-python
   ```

3. Execute o projeto:

   ```bash
   python gerador_senhas.py
   ```

> 💡 Certifique-se de ter o Python instalado. Você pode baixá-lo em: https://www.python.org/downloads/
